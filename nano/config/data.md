# 1. Pre-Training Data

**SextaFeira-V1** was pre-trained on **GigaVerbo2-Synth**, a synthetic Portuguese corpus.

### Overview

| Property | Value |
|---|---|
| Dataset | GigaVerbo2-Synth |
| Total tokens | ~4,9 billion |


The model was trained from scratch using approximately **4.9 billion tokens** of Portuguese text, with a basic data engineering pipeline applied before training.
